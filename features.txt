ResumeCraft - Implemented Features

## Core Features
1. **Personal Information**: 
   - First & Last Name
   - Contact Info (Email, Phone with Country Code Picker)
   - Location
   - LinkedIn Profile
   - GitHub Profile

2. **Education Section**:
   - Categorized entries (Class X (10th), Class XII (12th), Diploma, Degree, Post Graduate)
   - Score/Percentage/CGPA tracking

3. **Skills Management**:
   - Categorized selection interface (Frontend, Backend, Database, Mobile, DevOps, Tools, Languages, Soft Skills)
   - Custom skill addition

4. **Experience Tracking**:
   - Job history with Title, Company, Duration
   - Bullet point descriptions

5. **Projects Portfolio**:
   - Project names
   - Technologies used
   - Descriptions

6. **Resume Preview & Analysis**:
   - Real-time preview of the resume
   - Editorial/Minimalist layout
   - Automated analysis (completeness, action verbs, required fields)

## AI & Smart Features (New)
12. **ATS Optimization**:
    - **Real-time Scoring**: Calculates an ATS Score (0-100) based on content depth, keywords, and structural completeness.
    - **Smart Analysis**: Uses Apple's **NaturalLanguage** framework to analyze tone and keyword usage.
    - **Actionable Feedback**: Suggests specific improvements like adding strong action verbs, expanding bullet points, and including essential links (LinkedIn/GitHub).



14. **Enhanced Custom Sections**:
    - Added **Provider / Organization** name field.
    - Added **Date of Providing** field.
    - Added optional **Expiry Date** field.
    - Rendered across all templates (Classic, Simple, Modern) in both SwiftUI preview and HTML/PDF export.

15. **Resume Duplication**:
    - **Long-press context menu** on any resume with Duplicate and Delete options.
    - **Swipe-right** gesture reveals a teal Duplicate button.
    - Creates a full copy with a new ID and "(Copy)" appended to the title.

16. **Section Reordering**:
    - **Drag-and-Drop Interface**: Reorder resume sections (Experience, Education, Skills, etc.) via a simple list.
    - **Dynamic Templates**: All templates (Classic, Simple, Modern) automatically adapt to your custom layout.
    - **Custom PDF Export**: The generated PDF respects your exact section order.

17. **QR Code Integration**:
    - **Smart Links**: Generate QR codes linking to your LinkedIn, GitHub, or Portfolio.
    - **Template Integration**: Automatically placed in the bottom-right corner of Classic, Simple, and Modern templates.
    - **PDF Support**: Embedded as high-quality images in exported PDFs for easy scanning by recruiters.

18. **Responsive Toolbar**:
    - **Adaptive UI**: Toolbar automatically adjusts layout based on device orientation.
    - **Space Saving**: Groups "Share" and "Save" actions into a menu on compact screens (iPhone Portrait) to prevent clutter.
    - **Accessible**: Ensures critical actions are always reachable regardless of screen size.

19. **Smart Keyword Suggestions**:
    - **Context-Aware Recommendations**: Suggests missing high-value skills based on your primary role (e.g., specific Frontend frameworks).
    - **Power Word Detection**: Identifies and recommends strong action verbs ("Achieved", "Spearheaded") to improve impact.
    - **Interactive UI**: Displays suggestions as improved, clickable chips directly in the analysis view.

20. **Multi-Format Export**:
    - **Export As… Menu**: Toolbar dropdown lets you choose between PDF, Word (.docx), or Plain Text (.txt).
    - **DOCX Export**: Generates a valid Office Open XML document with formatted headings, bold entries, bullet lists, and proper margins — opens in Microsoft Word, Google Docs, and Pages.
    - **Plain Text Export**: Clean, ATS-friendly .txt output with section headers, contact info, and bullet points.
    - **No Dependencies**: Pure-Swift ZIP implementation for DOCX — no external libraries required.
    - **Section Order Respected**: All export formats honor the user's custom section ordering.

21. **Cover Letter Generator**:
    - **Auto-Fill from Resume**: Pulls your name, contact info, skills, experience, and projects directly from any saved resume.
    - **Three Tones**: Choose Formal (traditional business letter), Modern (clean and direct), or Creative (bold and expressive).
    - **Smart Text Assembly**: Generates a complete cover letter with opening, skills, experience, project highlights, and closing paragraphs — all tailored to the selected tone.
    - **Job-Specific**: Enter the company name, job title, and an optional hiring manager name for personalized greetings.
    - **Custom "Why" Paragraph**: Add your own reason for applying — it gets woven naturally into the opening.
    - **Beautiful Preview**: Full HTML preview matching the tone's visual style (serif for Formal, clean sans-serif for Modern, gradient header for Creative).
    - **PDF Export**: One-tap export to a professionally formatted PDF via the existing export pipeline.
    - **Copy to Clipboard**: One-tap copy of the entire dated cover letter as plain text — paste directly into emails or job portals.

22. **Smart Interview Prep Mode (Core ML Enhanced)**:
    - **Contextual Generation**: Uses Apple's **NaturalLanguage** framework to analyze your resume's bullet points and generate specific "Deep Dive" questions.
    - **Semantic Skill Matching**: Uses **NLEmbedding** to understand relationships between skills (e.g., inferring "Python" knowledge from "Django" or "FastAPI").
    - **Dynamic Question Bank**: Creates a unique set of 10 questions every session, prioritizing your specific achievements over generic templates.
    - **Flashcard Drill**: Interactive flip-card UI with questions on front and detailed answers/guides on back.
